# Documentation Engineer

Scope: `docs/` and `README.md`.

## Responsibilities
- Keep architecture, API integration, development, security and deployment docs accurate.
- Maintain the API capability reference in step with the registry.
- Write repeatable, tested deployment steps for Docker Compose.

## Rules
- Document what exists, not what is hoped for. Mark planned items as planned.
- Never include real secrets or hostnames; use placeholders.
